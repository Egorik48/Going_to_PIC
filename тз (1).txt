ТЗ

Нужно создать приложение приложение-шифровальщик на языке Python-3.14 с использование базы данных пользователей (sqlite3). Шифрует любой файл в картинку с помощью пароля.

Это приложение содержит:
0. База данных пользователей (users.sqlite)
1. Окно входа (login_window.py)
2. Окно регистрации (register_dialog.py)
3. Основное окно, где происходят преобразования (main_window.py)




0. База данных пользователей (users.sqlite):
Реализована на sqlite3и содержит такие колонки:
id - уникальный номер каждого пользователя (задаёт система)
login - уникальное имя (логин) пользователя (задаёт пользователь)
password - пароль, состоящий >= 7 символом, имея в записи цифры, заглавную букву и спец. символ (задаёт пользователь)



1. Окно входа (login_window.py):
Представляет собой окно (QWidget), где пользователю нужно авторизоваться для пользования приложения.

Виджеты этого окна: lineedit (для ввода логина и пароля), label (тут будет информация, чтобы пользователь, понял, что нужно делать, например, что он неправильно ввёл пароль, или, куда вводить логин, куда пароль), pushbutton (кнопка входа и регистрации)

В этом файле есть класс LOGIN. Наследуется от QWidget, QLoginUI
QLoginUI - код окна входа в приложение, сделанный с помощью QtDesigner

Функции класса: 
1. __init__ - связка класса с QLoginUI.
2. try_enter - при нажатии на кнопку входа, запускается метод, в котором открывается база данных и проверяются подходящие логины и пароли у пользователей. При неправильном пароле в linedit будет надпись о том, что пользователь неправильно ввёл пароль, иначе его перекинет в Основное окно, где происходят преобразования (main_window.py). Также есть проверка на пусты значения ввода (lineedit)
3. go_register - при нажатии на кнопку регистрации, запускается метод, который открывает окно регистрации (register_dialog.py)



2. Окно регистрации (register_dialog.py):
Представляет собой окно (QWidget), где пользователю нужно зарегистрироваться для пользования приложения.

Виджеты этого окна: lineedit (ввод логина, и пароля, и подтверждения пароля) label (тут будет информация, чтобы пользователь, понял, что нужно делать, например, что пароли не совпадают или что логин занят и т.д.) push_button (кнопка регистрации и входа)

В этом файле есть класс LOGIN. Наследуется от QWidget, QRegisterUI
QRegisterUI - код окна регистрации приложения, сделанный с помощью QtDesigner

Функции класса: 
1. __init__ - связка класса с QRegisterUI.
2. try_reg - при нажатии на кнопку регистрации, запускается метод, в котором открывается база данных и проверяются подходящие логины у пользователей. Если есть сходство, то label пишет, что логин уже занят и нужно его поменять, иначе проходит проверка на подходящий формат пароля (>= 7 символов, большая буква есть и т.д.), если формат правильный, то пользователя перекидывает в Основное окно, где происходят преобразования (main_window.py) и воспроизводится звук конфети, иначе, просит изменить пароль на валидный.
3. go_login - при нажатии на кнопку входа, запускается метод, который открывает окно входа (login_window.py)



3. Основное окно, где происходят преобразования (main_window.py):
Представляет собой окно (QWidget), где пользователь может ввести любой текст или прикрепить любой файл, ввести значение пароля (любые символы Unicode-а), а после этого выводится на экран картинка, которой можно поделиться.

Виджеты этого окна: QPlainTextEdit (ввод текста) label (тут будет информация, чтобы пользователь, понял, что нужно сделал, например, что он успешно преобразовал картинку) push_button (кнопка для копирования текста, и кнопка поделиться картинкой, и кнопка для создания картинки, и кпока для прикрепления файл), textbrowzer (для картинки), filedialog (для распознавания файла), QProgressBar (прогресс создания зашифрованной картинки)

В этом файле есть класс MAIN_WINDOW. Наследуется от QWidget, QMainUI
QMainUI - код окна главного приложения, сделанный с помощью QtDesigner

Функции класса: 
1. __init__ - связка класса с QMainUI.
2. create_pic - при нажатии на кнопку создания картинки, запускается метод, в котором программа считывает пароль и с помощью алгоритма (секрет) преобразовывает сырые байты в пиксели и выводит картинку в textbrowzer
3. share_it - при нажатии на кнопку поделиться, запускается метод, в котором картинка и пароль переходят в буфер обмена пользователя
4. recognize - при нажатии на кнопку распознания картинки, запускается метод, в котором открывается filedialog при просит передать картинку, после он с помощью пароля перегоняет пиксели обратно в сырой байт.
5. attach - при нажатии на кнопку прикрепления файла, запускается метод, в котором программа открывает filedialog при просит передать файл.
6. save_image - при нажатии на кнопку сохранения, запускается метод, в котором программа открывает filedialog и пользователь сохраняет картинку
7. save_restored_file - программа сохраняет восстановленный файл
